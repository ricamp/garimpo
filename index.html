Conectar ao GitHub

As faixas e as suas marcações ficam no arquivo dados/faixas.json do repositório privado ricamp/ric-skill-garimpo-musical. A página precisa de uma chave para ler e gravar nele. A chave fica guardada neste navegador e só é pedida de novo se o GitHub recusar.

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Nome: garimpo. Expiration: No expiration. Se essa opção não aparecer, escolha Custom e a data mais distante que ele aceitar.
  3. Repository access: Only select repositories → ric-skill-garimpo-musical.
  4. Permissions → Repository → Contents: Read and write. Mais nada.
  5. Gere, copie e cole aqui. Quando o navegador oferecer para salvar a senha, aceite: nos outros aparelhos ele preenche sozinho e você não precisa criar outra chave.
